# Вариант: SVG с ручной раскладкой (Python, без Graphviz)

Сборка: `python3 gen_slice_svg.py` → `slice_svg.svg` (CSS-переменные, тёмная тема по
`prefers-color-scheme`), `slice_svg.png` (1800 px) и `slice_svg.pdf` (Inkscape 1.2, текст в
кривых). Содержание — `../../slice_structure.dot` и `../../../slice.md`.

- Плюсы: координаты блоков заданы явно (сетка 10 px), только ортогональные линии со
  скруглением, толщина линии по пропускной способности, пересечения с разрывом (подложка
  цвета фона), подписи не перекрываются; один SVG для светлой и тёмной темы; правка — числа
  в скрипте, diff читаем в git.
- Минусы: любая правка состава требует ручной перекладки координат; около 10 пересечений
  (управление DMA/VPU и LD/ST через линии к памяти, QST через выходы MXU) — плоской
  раскладки без них не нашлось; в редакторе (Inkscape) правится, но генератор перезапишет.
