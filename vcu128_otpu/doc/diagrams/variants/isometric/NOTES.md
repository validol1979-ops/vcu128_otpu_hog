# Слайс openTPU — изометрия (вариант для выбора)

- `slice_isometric.html` — самодостаточная страница (без сети): наведение на блок — описание и ширина
  пути, `T` — светлая/тёмная тема, чанки 128 B бегут по порту B в FIFO MXU (стоят при reduced motion).
- `slice_isometric.svg` (светлая, стили встроены) и `slice_isometric.png` (1800 px) — статичные.
- Пересборка: `python3 build.py`, затем `inkscape slice_isometric.svg -w 1800 -o slice_isometric.png`.
- Генератор — перенос ядра скилла anatomy (камера 45°/30°, тела с тонами граней, порядок по лучу) на
  Python: node на машине нет. 188 деталей; содержание — только `slice_structure.dot` и `doc/slice.md`.
- Упрощено: массив MXU — 4 колонки × 8 строк (вместо 128), FIFO — 16 ячеек (вместо 1024), управление SEQ
  (пунктир на исходной схеме) — только в подсказках; otpu_coll при S = 1 не показан.
