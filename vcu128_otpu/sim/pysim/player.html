Что это. Потактовая модель одного слайса openTPU с параметрами VCU128 (D=128, 4 колонки MXU, 8 полос, окно 16), исполняющая программу одного токена маленькой Qwen3 (форма и веса — как у qwen-tiny в upstream Lens). Числа настоящие: INT8-квантование, точная целая сумма в MXU, FP32-эпилог, KV-кэш в HBM. Время модельное, сверено с RTL (±4 %).

Пути. LD: HBM → порт B → DMA → TMEM. MM: строки весов (или K-кэша, Vᵀ) из HBM → порт B → FIFO MXU; масштабы — порт A; стационарный операнд — из ACT RAM; результат FP32 → TMEM. QACT: TMEM → QUANT → ACT RAM. QST: TMEM → QUANT → порт SW → HBM (запись K/V). VOP: TMEM → VPU → TMEM.

Окно SEQ. Секвенсор кладёт по инструкции за такт в 16 слотов. Жёлтый слот ждёт старшую конфликтующую инструкцию (RAW/WAR/WAW по TMEM, HBM, ACT), зелёный исполняется. MM стартует в две фазы: сначала «поток» (веса уже грузятся в FIFO), затем «счёт», когда готов операнд в ACT RAM.

Почему так медленно считает MXU. При одном токене (M=1) работает одна колонка из четырёх, и каждая строка весов в 128 байт обрабатывается за такт. Скорость задаёт порт B: 128 B/такт = 12,8 ГБ/с при 100 МГц.
